# Seguridad

Este proyecto contiene documentación pública y ejemplos sin secretos. Las rutas administrativas y los datos operativos se gestionan en la instalación correspondiente.

## No publiques

- tokens, claves privadas o archivos `.env`
- IP, cookies, cuerpos de requests o datos de clientes
- capturas del Command Center o Grafana con información real
- artefactos de trials o auditorías internas

## Reportar un problema

No abras un issue público si el hallazgo puede afectar una instalación real. Contacta al mantenedor mediante el canal privado acordado y aporta una descripción mínima, versión afectada, pasos reproducibles sin datos sensibles y alcance observado.

No desactives el control de arranque ni publiques un exploit funcional para demostrar un problema.
