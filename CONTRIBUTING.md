# Contribuir

Las contribuciones deben mantener este repositorio como una superficie pública, clara y separada del runtime privado.

## Antes de abrir un cambio

- Comprueba que no incluya secretos, datos reales ni rutas internas
- Usa nombres de variables que coincidan con el contrato publicado
- Indica si un texto describe una garantía, un límite o una recomendación
- No presentes resultados de laboratorio como comportamiento humano
- Valida enlaces Markdown y el YAML de OpenAPI

## Cambios de configuración

Los ejemplos deben usar marcadores inválidos y explicar cómo se genera el valor real. Nunca uses una contraseña de prueba que alguien pueda copiar por accidente.

## Estilo

Escribe en lenguaje directo. Explica qué ocurre, qué riesgo existe y cuál es el siguiente paso. Evita claims de marketing y cifras sin ventana, fuente y método.
